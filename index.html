通訳つき会話

その場で話す → すぐ文字と翻訳 試用版

来場の方（iPad）

  1. 下のボタンから開く
  2. イベントコードを入れる（受付で案内されます）
  3. 話す言語を選ぶ — 日本語の方は「日本語ではじめる」を押すだけ
  4. 「マイクを許可して話す」を押して話す
  5. 終わったら「会話を終了」。次の方に交代できます
会話をはじめる

主催者の方（スマートフォン）

  1. 運営から受け取った 主催者リンク を開く（QR でも可）
  2. ホストキーを入れて「接続する」
  3. 表示名を入れて保存（相手の画面にこの名前で出ます）
  4. 「QR を表示」で来場者用の案内をいつでも出せます
  5. 最後に 「イベント終了・全データ消去」

主催者は日本語で話します（既定）。会話の終了は来場者の画面から行います。

この試用イベントは 1 回限り

「イベント終了・全データ消去」を押すと、会話の文字はすべて消去され、 この端末（サーバー）にも残りません。イベントコードもその場で無効になり、二度と使えません。

Pressing “End event” erases all conversation text from memory and invalidates the event code permanently. Nothing about the conversation is written to disk.

按「結束 event」後：所有對話即刻清除、電腦上唔會殘留、event code 立即失效。
